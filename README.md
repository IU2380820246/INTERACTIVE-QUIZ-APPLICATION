#DESCRIPTION:
This project is a simple interactive quiz website created to understand how question and answer based applications function inside a web browser. The purpose of the project is to practice JavaScript logic and dynamic page updates rather than building a full examination system. The quiz works completely on the client side and does not require login accounts, servers, or database storage.

The website presents multiple choice questions one at a time. The user selects an option and moves forward using navigation buttons. After the last question, the total score is calculated instantly and shown on the screen. The answer checking process is handled using JavaScript conditions, so results appear immediately without refreshing the page.

To make the quiz different on every attempt, the questions are shuffled using array operations. Because of this, the order changes each time the quiz starts, preventing users from memorizing answer positions. The quiz can be restarted any number of times and works independently on every attempt.

The design is kept clear and easy to read. Proper spacing and simple buttons help the user focus on answering questions without distraction. The layout adjusts automatically on different screen sizes, allowing the same page to work on both desktop and mobile devices.

While building this project, I practiced DOM manipulation, event handling, loops, and conditional statements in JavaScript. I also learned how user input can be processed instantly inside the browser environment. The project demonstrates how a small educational tool can be created using only basic front-end technologies.

Overall, this project represents a beginner-level quiz application that shows how questions, answer selection, and score calculation can be implemented in a lightweight web page.

#TECHNOLOGY USED:

CSS: styling and layout
JavaScript: quiz logic, randomization, and score calculation
